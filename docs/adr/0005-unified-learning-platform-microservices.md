## Context

用户希望统一登录后按权限选择语言学习或个人知识库，以真实项目学习 Spring Cloud、Dubbo 与 Spring AI Alibaba。两个项目的版本、身份入口及数据边界不同，尚不能按目标平台直接部署。

2026-10-20 用户确认首版采用统一 Vue 前端，按业务分区，前端统一构建发布、后端各服务独立发布（C23）。登录、应用选择、模型设置和导航集中维护，具体目录、路由、组件、依赖版本与托管方式待设计。用户前端学习重点是开发语言，实施时结合真实功能学习 TypeScript、JavaScript、HTML/CSS 和 Vue 基础，不引入微前端；具体实现分工仍在对应 slice 决定。本确认不授权当前迁移源码、安装依赖或实现前端功能，详见平台方案 §7 与部署方案 §5。

## Alternatives and Consequences

保留独立应用最简单，但不能满足已确认的平台方向；四服务方案增加网络、身份依赖、部署与维护成本，同时保持现有领域内状态和事务责任；细粒度拆分暂不采用。候选比较与影响见方案 §5、§7–8。
